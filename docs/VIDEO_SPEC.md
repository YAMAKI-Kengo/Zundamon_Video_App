# 動画の仕様書（ずんだもん解説動画の画面・動き・音）

このアプリが書き出す動画の「見え方・動き・音」の仕様を、別のアプリで同じ機能を作り直せる粒度でまとめたもの。
数値はすべて現在のコードの値（2026-10 時点）。座標・大きさは、特に断りが無ければ **画面の幅・高さに対する比率**。

- 対象のコード: `src/services/`（compositor・motion・staging・stage_fx・slide_renderer・telop・hook_text・pause_cue・
  video_builder・voicevox_client・voice_tone・bgm_library・lipsync・book_script）
- 「1シーン」＝台本の1セリフ（字幕1つ・音声1つ）。動画はシーンを順に並べてつなげたもの。

---

## 1. 全体の流れ

1. 台本JSON（§18）を読み込み、セリフごとに `Scene` を作る（`book_script.build_scenes`）。
   - 字幕が2行に収まらない長いセリフは、自然な位置で複数のシーンに分ける（§11.4）。
   - 黒板の箇条書きを「どのセリフで書き足すか」を決める（§9.6）。
   - 黒板が出たシーンには「読む時間」を足す（§15）。
2. VOICEVOX で各セリフの読み上げ時間を測り、表示秒数を決める（§13.5）。
3. シーンごとに映像と音声を作る（§2 のレイヤー順で合成）。
   - 動きの無いシーン: 「口:開」「口:閉」の2枚だけ合成し、口パクのフラグに合わせて並べる（高速）。
   - 動きのあるシーン（カメラ・キャラの動き・立ち位置の移動・黒板のアニメ・効果）: 1フレームずつ合成。
4. 全シーンをつなげ、BGM（§14）と効果音をミックスして MP4 に書き出す（§17）。

---

## 2. 画面とレイヤー

| 項目 | 値 |
|---|---|
| 横画面 | 1920×1080 |
| 縦画面（ショート） | 1080×1920 |
| フレームレート | 30fps（既定） |

1フレームの重ね順（下から）:

1. 背景（静止画 or 動画。雰囲気フィルタ §8.3）
2. 画面中央の「資料」レイヤー: 黒板 / イラスト / 解説カード / 本の表紙 / 資料メディア（どれか1つ）
3. キャラクター（立ち絵）＋キャラに付く効果（「！」・どんより線など §7）
4. ── ここまでをカメラ（ズーム・パン・揺れ）で拡大・移動 ──
5. 画面全体の効果（集中線・スピード線・フラッシュ §7）
6. 固定表示（カメラの影響を受けない）: 字幕・画面上部の見出し/フック・左上の目次ラベル・右上のPR表記

> 字幕などをカメラより後に重ねるのは、ズームしても字幕が拡大・移動しないようにするため。

## 3. キャラクター

### 3.1 素材
- 表情ごとに **口開き・口閉じの2枚の合成済み立ち絵**（`assets/<キャラ>/<表情>_open.png` / `_close.png`）。
- 表情一覧は `config/characters.json`。素材が無い表情は、プレースホルダー画像で代用（落ちない）。
- 余白の切り落とし: **そのキャラの全表情の絵が収まる範囲（和集合）** で一律に切る
  （表情ごとに切ると、ポーズで絵の範囲が変わったとき位置・大きさがズレるため）。
- バストアップ: 切り落とした絵の **上から72%** だけ使う（太もも位置でカット）。

### 3.2 いつもの立ち位置（2人実況レイアウト）
| キャラ | 水平中心 x | 備考 |
|---|---|---|
| 四国めたん | 0.095 | 画面左端寄り（体の一部が画面外） |
| ずんだもん | 0.905 | 画面右端寄り |
| 春日部つむぎ（ゲスト） | 0.27（縦画面 0.30） | めたん側 |

- 1人の最大サイズ: 幅 0.40、高さ 0.80（縦画面は高さ 0.34。上部の資料エリアを広く取るため）。
- 画面下端に揃える（余白0）。
- 重ね順（奥→手前）: つむぎ → めたん → ずんだもん。
- 素材がもともと向いている向き: **めたんは右、ずんだもん・つむぎは左**（`characters.json` の `"facing"`）。
  いつもの立ち位置では **素材の向きのまま**（反転しない）。

### 3.3 話者と聞き手
- 話者だけ口パク・セリフの表情。聞き手は口を閉じ、**待機表情**（`default_expression`）。
  シーンに `partner_expression` があれば聞き手もその表情（例: エンディングで2人とも笑顔）。
- `hide` に入れたキャラは描かない（声だけ）。
- ゲスト（つむぎ）は、そのブロックの `guests` に入っているか話者のときだけ描く。**黒板などを出しているシーンでは描かない**（黒板に重なるため）。

### 3.4 口パク（リップシンク）
- 音声（wav）を **1フレーム分のサンプルごとに RMS（-1〜1 に正規化）** で測り、**0.02 を超えたら口:開**。
- 音声より表示秒数が長い部分は口:閉。解析に失敗したら全フレーム口:閉（書き出しは止めない）。

## 4. キャラクターの動き（表情・指定に合わせた体の動き）

各シーンの `motion`（台本）／`char_motion`。`auto` のときは表情から決める。

### 4.1 自動のルール
- 表情 → 動き（**表情が変わった瞬間だけ**。話者交代・表情変更のシーン）:
  `panic→走り回る / shock→のけぞる / excited→はしゃぐ / cry→震える / angry→詰め寄る / gloomy・sad→しょんぼり`
- しょんぼり（slump）だけは、同じ表情が続く間ずっと沈んだまま（前後のシーンも沈むなら途中で戻らない）。
- 喜び・驚き・大興奮の表情に変わった瞬間は「ぴょん」と1回跳ねる。
- 話している間は「ゆらゆら（呼吸）」。
- 体を動かすシーンでは、カメラは寄らない（動きと相手の反応が見えるように）。

### 4.2 各動きの数値（幅は画面幅、高さは画面高さに対する比率）
| 動き | 内容 |
|---|---|
| bob（呼吸） | 周期 2.0秒、上下 0.006 |
| jump（ぴょん） | 0.4秒、高さ 0.035 |
| hop（はしゃぐ） | 0.3秒×3回、高さ 0.03 |
| panic（走り回る） | 画面の内側へ 0.13 の幅を往復（1往復 0.8秒、最長 2.4秒）。戻るときは左右反転、歩幅の上下 0.018 |
| recoil（のけぞる） | 外側へ 0.05・上へ 0.01。「素早く0.12秒→0.35秒止まる→0.5秒で戻る」 |
| lunge（詰め寄る） | 内側へ 0.07。0.18秒で寄って、セリフの終わり0.4秒で戻る |
| tsukkomi（ツッコミ） | 話者が内側へ 0.09（0.1秒→0.25秒→0.4秒）。相手は0.08秒遅れて外側へのけぞり（0.05）、0.08〜0.6秒は細かく震える |
| shiver（震える） | 左右 0.004、18Hz |
| slump（しょんぼり） | 0.35秒で下へ 0.08 沈む。最後の0.3秒で戻る（次も沈むなら戻らない） |
| nod（うなずき） | 0.28秒×2回、下へ 0.012 |

### 4.3 登場・退場（いつもの立ち位置のとき）
- 非表示→表示: 自分の側の画面外から 0.45秒で歩いて入る（1歩 0.16秒、上下 0.012）。
- 表示→非表示: 0.4秒で自分の側の画面外へ出ていく。
- 背景の場所が変わるシーン: 背景が 0.7秒で横に流れて新しい場所へ（部屋に戻るときは逆向き）、全員が歩いて入ってくる。

## 5. 立ち位置の演出（キャラが画面の中を自由に動く）

台本の各セリフの `stage` で指定（§18）。**指定はセリフをまたいで引き継ぐ**（書かなければ前のセリフの終わりの状態のまま）。
台本に `stage` が無いブロックは、§5.7 の自動の演出で動かす（英会話を除く。設定でオフにするといつもの画面のまま）。

### 5.1 状態
キャラごとに `x`（立ち位置の中心）・`scale`（いつもの大きさに対する倍率）・`facing`（向き: 左/右/素材のまま）。
各セリフで「始まりの状態（＝前のセリフの終わり）→ 終わりの状態」を決め、セリフの頭で移動させる。

### 5.2 値
| 立ち位置 `pos` | x |
|---|---|
| out_left / out_right（画面の外） | -0.3 / 1.3 |
| far_left / left / center_left | 0.1 / 0.2 / 0.36 |
| center | 0.5 |
| center_right / right / far_right | 0.64 / 0.8 / 0.9 |
| home | いつもの立ち位置（§3.2） |

| 大きさ `size` | 倍率 |
|---|---|
| small（遠く） | 0.72 |
| normal | 1.0 |
| large（手前） | 1.22 |

- `face`: left / right。空なら **一番近い（画面内の）相手の方を向く**。1人なら画面の中央を向く。
- 重ね順: 大きさが小さい人ほど奥に描く（遠近感）。

### 5.3 ショット `shot`
| 値 | 動き |
|---|---|
| talk | 全員いつもの立ち位置へ戻る |
| solo | 話者だけ中央（x=0.5）・large。他は近い方の画面外へ |
| closeup | 話者の顔へ 0.25秒でズーム（横 1.6倍・縦 1.4倍） |
| group | 全員を中央に等間隔で並べる（2人: 0.38〜0.62、3人以上: 0.32〜0.68。今の左右の並び順を保つ。体が重なるなら §5.4 の間隔まで中央から広げる） |
| wide | 全員を 0.22〜0.78 に等間隔・small（引きの画。場所の背景が見える） |

キャラごとの指定（`cast`）はショットのあとに上書きする。

### 5.4 動き方 `move`
| 値 | 動き |
|---|---|
| walk（既定） | 速さ 0.55画面幅/秒。歩幅の上下 0.012（1歩 0.16秒） |
| run | 1.5画面幅/秒。上下 0.022（1歩 0.11秒）。移動距離 0.6 を超えると自動で run |
| jump | 0.55秒で放物線（高さ 0.12） |
| step_back | 0.22画面幅/秒。**向きを変えずに**下がる。`pos` が無ければ相手から 0.11 離れる |
| approach | `pos` が無ければ、体が重ならない距離（§5.4 の最小間隔）まで相手に近づく |
| retreat | `pos` が無ければ相手から 0.18 離れる |
| chase | run と同じ。効果の指定が無ければスピード線を付ける |
| turn | その場で振り向く（0.1秒後に 0.2秒で向きが変わる） |
| enter | 画面外から（いなければ）いつもの立ち位置へ入る |
| exit | 近い方の画面外へ出ていく |

- 移動時間 = 距離 ÷ 速さ（0.35〜1.6秒に収める）。補間は smoothstep（`p²(3−2p)`）。
- 話者は即座に、話者以外は 0.1秒遅れて動き出す。
- **移動中は進む方向を向く**（step_back を除く）。止まったら §5.2 の向き。
- 立ち位置が移動する話者には、表情からの自動の動き（§4.1）を重ねない（走り回る＋移動 が喧嘩しないように）。
- **体が重ならない最小間隔** = (Aの体の幅×Aの大きさ ＋ Bの体の幅×Bの大きさ) ÷ 2 × 1.05。体の幅は立ち絵の顔〜胴体（上から15〜60%）の不透明部分の幅で、横画面で めたん0.26・ずんだもん0.29・つむぎ0.23、縦画面で約0.34。これより近いときは、`pos` を指定していない方を最小間隔までずらす（画面外に出るなら反対側をずらす。3人以上でも収まるまで繰り返す）。
- 非表示になったキャラは近い画面外へ歩いて出る。新しく表示されたキャラは画面外から入る。

### 5.5 黒板との関係
- 黒板・イラスト・解説カード・本の表紙・資料を出すセリフでは、**全員が自動でいつもの立ち位置に戻る**（黒板に重ならない）。
- 立ち位置の演出を使うブロックでは、黒板は「黒板を出すセリフにはさまれた区間」だけ出す（§9.7）。

### 5.7 自動の演出（台本に `stage` が無いブロック）
セリフの表情・流れから、1セリフに1つまで演出を付ける（気持ちが動いたセリフで動かす。ランダムには動かさない）。上から順に判定:

| 条件 | 演出 |
|---|---|
| 場面転換テロップ（「3日後…」）の直後 | 引きの画（wide） |
| はしゃぐ（excited）・導入での喜び（happy）に表情が変わった | 話者が中央へ走り出て large |
| ショック・驚きに変わった | 話者が後ずさる |
| 焦り（panic）に変わった | 話者が相手と反対側の端へ走って逃げる（相手を横切らない） |
| 落ち込み・悲しみ・大泣きに変わった | 話者が相手と反対側の端へ歩いて small |
| 端にいるときにひらめき（idea） | 跳んで中央へ戻る |
| ツッコミ（motion tsukkomi）・怒り・ひそひそ | 話者が相手に近づく |
| 黒板の無い会話が3セリフ以上続く | 2人が中央に寄って向かい合う（group） |
| 同じ構図が4セリフ続いた | group と wide を入れ替える |

黒板などを出すセリフでは何もしない（§5.5 で左右に戻る）。

### 5.6 カメラ `camera`（演出用）
| 値 | 動き |
|---|---|
| pan_left / pan_right | 1.18倍に拡大し、セリフの間に横へ 0.12 動く |
| zoom_in | セリフの間に 1.0→1.2倍（話者へ） |
| zoom_out | 1.35倍から 0.9秒で 1.0倍へ |
| follow | 1.2倍で、移動する話者の顔を追う |

## 6. カメラ（自動）と画面の揺れ

| 種類 | 内容 |
|---|---|
| 話者にパッとアップ | 0.25秒で横 1.28倍（縦 1.2倍）。焦点は話者の顔（立ち絵の上から22%） |
| 話者にゆっくりアップ | シーンの間に +15% |
| 全体のゆっくりズームイン | 同じ黒板のブロックの最後までに +5%（画面中央・高さ0.4を中心） |

- 自動のとき: 驚き・ショック・大興奮・怒り・大泣き・ひらめきの表情で「パッとアップ」、解説の黒板中は「ゆっくりズームイン」。
- 拡大の枠は画面からはみ出さないよう端で止める。
- 揺れ: 0.6秒・振れ幅 0.012（指数減衰 τ=0.18秒、横16Hz・縦13Hz）。揺れるシーンは端が見えないよう 1.03倍にしておく。
  自動で揺らすのは、ショック顔のとき・`se_guide.json` で `"shake": true` の効果音のとき。

## 7. 漫画風の効果 `fx`

| 値 | 描き方 |
|---|---|
| focus_lines（集中線） | 話者の顔を中心に放射状のくさび110本（暗い半透明 (30,30,40,150)）。内側の空白は短辺の0.36倍。0.08秒ごとに3パターンを切り替えてちらつかせる。1.8秒表示（最後の0.3秒でフェード） |
| speed_lines（スピード線） | 白い横線45本（半透明）。0.08秒ごとに4パターン。1.8秒 |
| flash | 白を最大 alpha 220 で重ね、0.35秒で消える |
| gloom（どんより） | 頭の上に紫の縦線9本（立ち絵の幅0.8・高さ0.45の範囲）。0.3秒でフェードイン、シーン中ずっと |
| exclaim / question | 赤の「！」/青の「？」（白の縁取り） |
| sweat | 水色のしずく |
| anger | 赤い怒りマーク（4つの弧） |
| sparkle | 黄色い星3つ |

- マーク類は **カメラの後** に、話者の顔の横（顔の高さ。相手と反対側に立ち絵幅の0.32）へ出す。大きさは min(立ち絵の高さ×0.22, 画面の高さ×0.13)。
  画面の端からはみ出すときは顔の反対側に出し、さらに画面の内側（端から高さ×0.02・上下は 高さ×0.62 まで）に収める（大きく映っているとき・アップのときに切れないように）。
  0.18秒でポンと弾んで現れ、1.8秒表示、ゆらゆら上下。
- 集中線・スピード線・フラッシュ・マークはカメラの後、どんより線はカメラの前（ズームで一緒に大きくなる）。
- 自動の効果（設定でオン/オフ。表情が変わった瞬間だけ）:
  `surprised→！ / shock→集中線 / panic・troubled→汗 / angry→怒り / gloomy→どんより / think→？ / idea・excited→キラキラ`

## 8. 背景

### 8.1 画面へのはめ込み
- 画面の向きと大体合う画像は、画面いっぱいに拡大して中央で切る（切り落とすのは幅/高さの35%まで）。
- それ以上切らないと入らない画像（横長の背景を縦画面に使う等）は、絵を全部見せて、余白を **同じ絵をぼかして暗くしたもの**（ぼかし 短辺の4%、明るさ 0.8）で埋める。
- 全体のぼかし（設定）: 立ち絵を目立たせるための軽いぼかし。

### 8.2 場所の背景
- ブロックごとに `background`（手元の背景）を指定。回想・寸劇などで部屋以外の場所を見せるときだけ使う。
- 場所が変わるシーンは §4.3 のとおり背景が横に流れ、キャラが歩いて入ってくる。

### 8.3 雰囲気フィルタ `mood`（背景だけに掛ける。キャラ・黒板・字幕はそのまま）
| 値 | 明るさ | 彩度 | 色の重ね（RGB, 濃さ） |
|---|---|---|---|
| gloomy（落ち込み） | 0.55 | 0.45 | (40,60,120), 0.28 |
| shock（ガーン） | 0.5 | 0.15 | (60,50,90), 0.2 |
| dark（夜・不安） | 0.42 | 0.8 | (10,15,40), 0.2 |
| sepia（回想） | 0.95 | 0.0 | (150,105,55), 0.38 |
| bright（大成功） | 1.12 | 1.2 | (255,240,200), 0.1 |

- 動画の最初のシーンには付けない。2シーン以上続けて付ける（1シーンだけはチカチカするので外す）。1本で3場面まで。

## 9. 黒板

### 9.1 置き場所（「資料」レイヤー共通の枠）
| | 最大幅 | 最大高さ | 上端の余白 |
|---|---|---|---|
| 横画面 | 0.62 | 0.73 | 0.03 |
| 縦画面 | 0.94 | 0.60 | 0.04 |

- 水平中央。ゲストが画面にいるときは 0.78倍に縮める。
- 黒板の画像は枠にぴったりのサイズで生成（拡大縮小でぼやけない）。

### 9.2 黒板の絵（素材を使わずプログラムで描く）
- 深緑の地 (36,66,52) ＋ 大きなムラ（低周波ノイズ）＋ 細かい粒子 ＋ 消し跡のかすれ。
- 木枠（太さ 短辺の3.5%、色 (128,88,52)）、下にチョーク受け（高さ 短辺の4.5%、チョーク数本）、ドロップシャドウ（余白 2.5%）。
- 乱数のシードは内容から決める（同じ内容なら何度描いても同じ絵）。
- 縦画面用に、ホワイトボード（アルミ枠・マーカー）のスタイルも用意（見出し青・本文黒・強調赤）。

### 9.3 文字
| 項目 | 値 |
|---|---|
| フォント | `assets/fonts/chalk*` があればそれ（手書き風）、無ければ Noto Sans JP |
| 見出し | 黄色チョーク (250,226,120)・中央揃え・手書き風の下線。サイズ = 基準×0.088 |
| 箇条書き | 白チョーク (244,244,236)・左揃え（ブロックごと中央寄せ）。サイズ = 基準×0.07 |
| 強調 `**語**` | ピンクのチョーク (255,168,184) |
| 基準 | min(黒板の高さ, 黒板の幅÷1.3) |
| 内側の余白 | 左右 6%・上下 8% |
| 行送り | 文字サイズ×1.45、項目間 +0.25、見出しと本文の間 +0.8 |
| 太らせ | 縁取り 文字サイズ×0.032 |

- チョークの質感: 文字のマスクにノイズを掛けてかすれさせ、周りに薄い粉のにじみ。
- 手書き感: 1行ごとに ±0.7°（本文は ±0.42°）傾け、上下に ±3〜4% ずらす。
- 行頭: 「・」の丸、または番号付き（`numbered: true` のとき「1.」「2.」を下線と同じ色で）。

### 9.4 収め方
- **1項目＝1行（基本は折り返さない）**。一番長い項目が1行に収まるまで、全項目を同じサイズで縮める（余裕 0.96）。
- 縮めると通常の 0.8倍より小さくなる項目だけ、自然な位置（§11 と同じ基準）で2行に分ける。
- 「英文 ― 訳」のように「―」で対になった項目は、いつも2行に分ける。
- 全体が高さに入らなければ全体の倍率を 0.92倍ずつ縮める（下限 0.45）。少ないときは 1.15倍まで大きく。
- 上下は「少し上寄りの中央」（余った高さの 40% を上に）。
- フォントに無い記号は置き換え（①→1、→→＞、●→〇 など）、それ以外は取り除く（豆腐防止）。
  **矢印はきれいに出ないので、黒板では言葉で書く運用**にしている。

### 9.5 見出しの表記
- 「ポイント1 〜」のような見出しは「ポイント1：〜」に自動でそろえる（番号のあとに全角の「：」）。

### 9.6 箇条書きの書き足し（1行ずつ増える）
- 同じ黒板のブロックの中で、各行は **その内容を初めて話すセリフ** で書き足す:
  1. 台本の `bullet`（行番号）があればそのセリフ
  2. 無ければ、黒板の文とセリフの似ている度合い（文字の2-gram）で対応を探す（しきい値 0.3）
  3. それでも無ければ、黒板を出しているセリフの数に比例して振り分ける
- まとめ（summary）の黒板は最初から全部の行を出す。
- 書き足しのアニメ: 増えた文字を上の行から順に、各行は左から右へ 0.8秒で書いていく（シーンが短いときはシーンの半分まで）。
- 書いた行の位置・見た目は、行が増えても1ピクセルも変わらない（文字の大きさ・配置は常に全項目ぶんで計算）。

### 9.7 黒板の出し方
- `board: true` のセリフで出す。
- 演出（stage）を使わないブロック: 一度出したらブロックの最後まで出したまま（チカチカ防止）。
  ただし解説（explain）のブロックでは、**箇条書きを全部書き終えたセリフの次のセリフまで** で黒板を片付け、残りのセリフは会話と自動の演出で見せる（英会話は除く）。
- 演出を使うブロック: 最初に黒板を出したセリフ〜最後に出したセリフの間で、演出の指定が無いセリフだけ出したまま。
- 黒板の切り替えアニメ: 別の黒板へ 0.5秒（スライド: 古い黒板が左へ出て新しい黒板が右から入る / フェード / ワイプ。設定で選ぶ）。
  会話だけの画面から出るときは 0.25秒でふわっと、消えるときも 0.25秒でフェード。

## 11. 字幕（テロップ）

### 11.1 見た目
| 項目 | 横画面 | 縦画面 |
|---|---|---|
| 1行の最大文字数 | 30字 | 17字 |
| 最大行数 | 2行（超えるセリフはシーンを分ける） | 同左 |
| 文字サイズ | min(短辺×0.05, 最大幅÷(字数+0.4)) | 同左 |
| 最大幅 | 画面幅の 0.85 | 同左 |
| 位置 | 画面下端から 0.05 上 | 中心が高さ 0.6 |

- 白い角丸の箱（(255,255,255,235)、角の丸み 文字×0.35、内側の余白 左右 文字×0.6・上下 文字×0.35）。
- 文字色・縁取り・箱の枠の色はキャラごと（`characters.json` の `telop`）。例: ずんだもん 文字 #2B7A1C・枠 #5FAE3E、めたん 文字 #C8306E・枠 #E39AB8。
- 縁取り 文字×1/18、行間 文字×0.35。
- 英語のセリフは訳を下に小さく（字幕の0.72倍、#555555）。

### 11.2 改行のアルゴリズム（日本語）
入力した改行は尊重し、各段落を「1行の最大文字数」以内の塊に分ける（`telop.split_natural`）。

1. 必要な行数の最小値 `n = ceil(文字数 / 上限)` を求める。`n` 行に分ける案と、`n+1` 行に分ける案（+3点の減点）の両方を比べる。
2. 1行目の切れ目の候補 `i` ごとに、`点数 = 切れ目の不自然さ + |i − 理想の長さ| × 0.2` を計算し、最小の位置で切る。残りに同じことを繰り返す。
3. 切れ目の不自然さ（小さいほど自然）:

| 切れ目の前後 | 点数 |
|---|---|
| 次の文字が句読点・閉じ括弧・小さい文字（ぁ ゃ っ ー …）・！？ | 1000（禁止） |
| 前が文の終わり（。！？…） | 0 |
| 前が読点（、，,） | 1 |
| 前が閉じ括弧 | 2 |
| 「」『』の途中 | 40 |
| 数字＋単位（円・人・%・倍・日・分・回・個・件・秒・枚・本・冊・歳・割）の直後 | 3 |
| 漢字の直後にひらがな（送りがな・助詞の前） | 12 |
| 助詞（は が を に で と も へ の や か よ ね わ）の直後で、次が漢字・カタカナ・英数字 | 2 |
| ひらがなの直後で、次が漢字・カタカナ・英数字 | 4 |
| 文字の種類が変わる位置 | 5 |
| カタカナ語・数字・英単語・熟語の途中 | 30 |
| その他 | 8 |

- 「お」「ご」＋漢字（お風呂・ご飯）は、漢字の言葉の頭として扱う。
- 半角が多くて幅がはみ出す行は、さらに幅で折り返す（行頭禁則あり）。

### 11.3 英語の字幕
単語の切れ目で折り返し、2行になるときは「文の終わり（. ? !）＞ カンマ（, ; :）＞ その他」を優先しつつ、2行の長さがそろう位置で分ける。

### 11.4 長いセリフの分割
字幕が2行に収まらないセリフは、まず「2行分の文字数」で自然な位置で塊に分け、それでも3行以上になる塊は1行ずつに分けて、**別のシーン**にする。分けた2つ目以降は効果音・本の表紙・カメラの指定を付けない。

### 11.5 表示しない文字
フォントに字形が無い絵文字・記号は取り除く（丸数字・矢印などはフォントにある文字に置き換え）。

### 13.4 読み方

### 13.5 表示秒数
- VOICEVOX の `audio_query` の長さ情報から、合成せずに読み上げ時間を計算 → `読み上げ時間 + 0.15秒`（ショート 0.03秒）。
- 最短 1.0秒（ショート 0.6秒）。VOICEVOX が無いときは文字数から概算（6字/秒 × 話す速さ）。

## 14. BGM と効果音

### 14.1 BGM の選び方（何も設定しなくても流れる）
- 曲は `assets/bgm/<雰囲気>/` に置く。雰囲気: calm（日常・解説）/ bright（楽しい）/ comedy / tense（緊張）/ serious / emotional（感動・悲しい）/ mysterious（謎）、＋ none（無音）。
- **雰囲気の決め方**: 台本の各セリフの `bgm` があればそのセリフから切り替える。無ければブロック（場面＋段階＋黒板の見出しが同じ区間）ごとに推定する:
  - 場面の基本: 導入の決意 bright、導入の失敗 comedy、めたん登場 calm、解説 calm、まとめ bright＋calm、エンディング bright（重みを2倍）
  - 足し点: 背景の雰囲気（落ち込み・回想→emotional、夜・ショック→tense、明るく→bright）3点、効果音（ボヨヨーン・チーン等→comedy、運命・ショック等→tense、ファンファーレ等→bright）1.5点、表情（大泣き・悲しみ・どんより→emotional、ショック・焦り→tense、喜び・大興奮・笑い・ひらめき→bright、ドヤ顔・怒り→comedy、考え中→mysterious）1点、ツッコミ→comedy 1点、黒板→calm 0.5点
- **8秒未満で終わる雰囲気の区間は前の曲のまま**（無音だけは1秒以上あれば効かせる）。
- **曲の決め方（ランダムなし）**: 雰囲気のフォルダの中から、曲の音を解析した特徴（`_library.json` の `features`）の点数が一番高い曲。
  - 全雰囲気共通「セリフの邪魔をしにくいか」: −1.0×音量の起伏（log）−0.6×にぎやかさ −0.4×max(0, 音の明るさ)（いずれも全曲で標準化した値）。
    雰囲気ごとの重み: calm 1.6 / serious・mysterious 1.2 / emotional 1.0 / tense 0.9 / bright 0.8 / comedy 0.6
  - 雰囲気ごとに好む特徴: bright 明るさ+0.6・にぎやかさ+0.4 ／ comedy にぎやかさ+0.6・明るさ+0.3 ／ tense 明るさ−0.3 ／ serious にぎやかさ−0.2 ／ emotional にぎやかさ−0.5・明るさ−0.2 ／ mysterious にぎやかさ−0.3
  - その雰囲気が一番長く続く区間の半分より短い曲は −0.5（ループが目立つため）
  - 特徴: にぎやかさ＝目立つ音の頭の数/秒、音の明るさ＝スペクトルの重心(Hz)、音量の起伏＝RMSの95パーセンタイル÷20パーセンタイル（曲の頭120秒）。テンポは推定が不安定なので使わない
- 優先順: シーン個別の曲 ＞ 台本の雰囲気（`bgm`）の曲 ＞ 利用者が選んだ場面ごと・全体の曲（**ファイルがある場合だけ**。古い場所の設定は無視）＞ 推定した雰囲気の曲。
  雰囲気ごとの曲は、利用者が選び直した曲があればそれを使う。

### 14.2 ミックス
- 同じ曲が続く区間を1つにまとめ、曲が短ければループ、長ければ切る。
- 曲が変わる境界: 1.2秒のクロスフェード（区間の1/3まで）。動画の頭・お尻・無音との境界: 1.5秒のフェード。
- 曲ごとの音量をそろえる: 曲の頭90秒の RMS を測り、**0.12 になる倍率（0.4〜2.5倍）** を掛けてから、BGMの音量（既定 0.15）を掛ける。

### 14.3 クレジット
- 説明文には **実際に流れた曲だけ** を「曲名 / 作曲者 様」で載せる（配布元ごとに「・BGM：配布元（URL）」の見出し）。
- 作曲者が書き方を指定している曲は、その文をそのまま（同じ表記は1回だけ）。曲情報は `assets/bgm/_library.json`。

### 14.4 効果音
- セリフの頭で鳴らす（`se`）。音量は設定（`se_volume`）。シーンより長い効果音はシーンの終わりで 0.3秒フェードアウトして切る。
- `config/se_guide.json` で `"shake": true` の効果音は画面を揺らす（§6）。

## 19. 別のアプリで作るときの要点
- **状態を持つ**: 立ち位置・大きさ・向きはセリフをまたいで引き継ぎ、セリフの頭で前の位置から補間する（瞬間移動させない）。
- **固定表示はカメラの後**: 字幕・見出し・ラベルはズーム・揺れの影響を受けないよう最後に重ねる。
- **黒板と立ち位置の排他**: 黒板などを出すときはキャラを左右に戻す。黒板は結果を見せる短い区間だけにする。
- **1行に収める・自然な位置で切る**: 字幕・黒板とも、§11.2 の点数で切れ目を選ぶと読みやすい。
- **同じ内容なら同じ絵**: 黒板・効果のパターンは内容から決まるシードで描き、プレビューと本番で見た目を一致させる。
- **音量は2段階でそろえる**: 声は RMS 0.17 に、BGM は曲ごとに RMS 0.12 にそろえてから全体の音量を掛ける。
