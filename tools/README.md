# ⚠️ このフォルダは販売者専用です。購入者には絶対に渡さないでください。

`tools/` フォルダには、ライセンスキーを発行するための鍵ペア生成スクリプト
(`generate_keypair.py`)・キー発行スクリプトが入っています。キー発行スクリプトは
2種類あり、購入者ごとに都度1件発行する`generate_license_key.py`と、Payhip等の
「事前生成キーをアップロードする」機能向けにまとめてN件発行する
`generate_license_keys_bulk.py`があります（使い分けは`SELLING_GUIDE.md`参照）。

- これらのスクリプトと、`generate_keypair.py`実行後にここへ生成される
  `private_key.pem`（秘密鍵）は、**販売者だけが持っているべきもの**です。
- 実行ファイル(exe/app)をビルドして配布する際、このフォルダが `dist/` の中に
  混入していないことを必ず確認してください（`packaging/BUILD.md` の手順通りに
  `.spec` ファイルの `datas` を指定していれば含まれないはずですが、念のため
  目視確認することを強く推奨します）。
- `private_key.pem` が万が一漏れると、誰でも「本物として検証が通ってしまう」
  ライセンスキーを自由に作れるようになってしまいます。Gitにコミットしない・
  クラウドの共有フォルダに置かない等、取り扱いに注意してください。

詳しくは `SELLING_GUIDE.md` を参照してください。
